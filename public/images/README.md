# Photos

Drop real photos here with these exact names, then run `npm run build`.
The site automatically swaps each placeholder for the photo. Not copied to dist/.

| File name               | What                                            | Shape / size          |
|-------------------------|-------------------------------------------------|-----------------------|
| `winton-minivan.jpg`    | **Hero**: Winton with the Toyota minivan        | portrait 4:4.6, 1200px+ tall ideal |
| `winton-portrait.jpg`   | Friendly photo of Winton ("Meet Winton")        | 4:4.4, 800px+         |
| `winton-avatar.jpg`     | Face crop for the round driver-card avatar      | square, 240px+        |
| `minivan-exterior.jpg`  | The minivan (currently: trunk full of luggage)  | landscape 16:10, 1600px+ |
| `airport-luggage.jpg`   | Airport pickup / loading luggage                | landscape 16:10, 1600px+ |
| `og.jpg` (optional)     | Social share image (WhatsApp/Facebook previews) | exactly 1200×630      |

V1 photos (Sept 2026) are crops of Winton's own WhatsApp photos (#13, #36, #15, #06), lightly exposure/colour corrected. No AI alterations. Replace with a proper photo session when possible.

Tips
- Compress before uploading (e.g. squoosh.app): aim for < 250 KB each.
- Adding a `.webp` next to the `.jpg` with the same name is picked up automatically.
- Shoot in daylight, minivan freshly washed, Winton smiling and looking at the camera.
- If `og.jpg` is missing, the hero photo (or the generated `og-default.png`) is used.
